# FitYaar

FitYaar is a complete **fitness web application + AI-powered gym training platform** built to make workouts smarter, more interactive, and more accessible. It combines a modern web experience with a dedicated machine learning engine for workout guidance and pose-based training analysis.

### Live Demo
- **FitYaar:** https://fit-yaar.vercel.app/
- **Deployed AI_GYM_TRAINER:** https://marvelous-sherbet-c11eb1.netlify.app/

### Core ML Repository
- **AI Gym Trainer:** https://github.com/Khushisgh01/AI_GYM_TRAINER

> The **AI Gym Trainer** repository powers the machine learning / pose-estimation part of FitYaar and serves as the core AI engine behind the fitness training feature.

---

## Project Description

FitYaar is designed to provide users with a complete digital fitness experience.  
The platform combines:
- a clean and responsive web interface,
- AI-based workout assistance,
- and an independent ML module for exercise tracking and pose estimation.

This project reflects both **web development** and **machine learning** integration in one ecosystem.

---

## Features

- AI-powered gym workout support
- Real-time fitness and exercise assistance
- Clean, responsive, user-friendly interface
- Separate ML engine for pose estimation and training analysis
- Modern landing page and deployed frontend
- Easy integration between frontend and AI module

## Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/Khushisgh01/FitYaar.git
cd FitYaar
```
### 2. Install dependencies
```bash
npm install
```
### 3. Start the development server
```bash
npm start
If your project uses a different command such as npm run dev, use that instead.
```
